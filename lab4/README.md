# Лабораторная работа 4 — веб‑интерфейс (FastAPI)

Цель: сделать клиент‑серверный интерфейс для модели из ЛР1, сохранив общий код и работоспособность CLI.

## Совместимость с ЛР1
- Доменные сущности и логика: `lab1/domain/*`
- Исключения: `lab1/exceptions.py`
- Хранилище: `lab1/persistence/json_storage.py`
- Генератор ID: `lab1/services/id_generator.py`
- CLI: `lab1/main.py`

Веб‑интерфейс подключает общий код из `lab1` через `sys.path` и работает с тем же файлом состояния: `lab1/data/storage.json`.

## Как запустить
1. Установить зависимости (внутри виртуального окружения):
   - `pip install -r lab4/requirements.txt`
2. Запустить сервер:
   - `uvicorn lab4.app:app --reload`
3. Открыть в браузере:
   - `http://127.0.0.1:8000`

Фото доступны как статические файлы по пути `/photos/<имя_файла>`.

## Возможности интерфейса:
- Показ карты и выбор достопримечательности по клетке
- Просмотр информации о достопримечательности
- Просмотр фото
- Публикация отзывов и просмотр отзывов
- Создание маршрута, добавление/удаление точек
- Публикация, снятие с публикации, архивирование маршрута
- Списки достопримечательностей и маршрутов
